Holographic leaderboard NPCs displaying top player stats and skins for **Minecraft Forge 1.20.1**.

## Features
- **Dynamic Skin Fetching:** NPCs automatically adopt the skins of top-ranked players.
- **Categories Supported:** Balance/Money, Playtime Hours, Kills, Deaths, Claims, and Plots.
- **3D Floating Holograms:** Renders custom floating holographic text above the NPC.
- **Auto-Refresh:** Periodically updates leaderboards from the database.

## Commands
| Command | Permission | Description |
| :--- | :--- | :--- |
| /topnpc spawn <category> <1-3> | OP | Spawns a leaderboard NPC for Rank 1, 2, or 3 |
| /topnpc remove | OP | Removes the closest leaderboard NPC within 3 blocks |
| /topnpc refresh | OP | Forces an immediate database leaderboard refresh |

## Requirements
- Minecraft Forge **1.20.1** (47.4.18+)
- Java **17**
- **EvoCore** 1.0.0+
